## How I work

- **Plan first.** A task starts with a plan; nothing changes until it is approved.
- **Compile online.** Heavy toolchains belong in CI, not on an old local machine.
- **Measure, don't invent.** No backdated commits, no made-up benchmarks.
- **Keep it small.** Prefer simple, self-hosted tools over another subscription.
